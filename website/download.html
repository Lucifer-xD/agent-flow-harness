Questions

Before you install.

Is it really free?

Yes. AFH itself costs nothing and needs no account (an account is optional, only to reach your computer from the phone app). You pay your model provider as usual — or nothing extra if you sign in with a ChatGPT or Copilot plan you already have, or run models on your PC.

Do I need an API key?

No. You can sign in with ChatGPT (Plus, Pro or Team) or GitHub Copilot, or use a model running locally in Ollama, LM Studio, vLLM, llama.cpp or Jan. API keys work too, for 228 providers.

Where does my code go?

Only to the model providers you set up. Threads, settings and keys stay on your PC in %USERPROFILE%\.afh. The app sends no telemetry. Our server log counts downloads, visits and apps in use (from update checks and phone sign-ins) as daily totals, and that never includes your code or chats.

Why does Windows warn me about it?

SmartScreen warns about apps it hasn't seen many times before. Choose More info → Run anyway. You can check the file's SHA-512 against the one on this page first.

How safe is reaching my computer from the phone?

Only your account can reach your computers, and you choose which computers are signed in. Everything goes over HTTPS through agentflowharness.com, which passes it along without keeping it: the server stores your email, a hash of your password and the list of your computers — never your threads, files or keys. Anyone signed in to your account can use AFH on your computer like you, so use a strong password. Turn it off any time in Settings → Remote control.

How do I open AFH on a Mac?

Open the DMG and drag AFH to Applications. The app isn't signed by Apple yet, so the first time, macOS won't open it. Go to System Settings → Privacy & Security and choose Open Anyway. You only do this once. If macOS says the app is damaged, run xattr -dr com.apple.quarantine "/Applications/Agent Flow Harness.app" in Terminal. New versions are a download, and AFH tells you when one is out. Computer use is Windows only.

Is there a Linux version?

Yes, in the terminal: one command installs it. The desktop window is Windows and Mac only.

How do I uninstall it?

Desktop app: open Settings → Apps in Windows, find Agent Flow Harness and choose Uninstall. Terminal app: run afh uninstall. Either way your threads and keys stay in the .afh folder in your home folder; delete it to remove them too.

Do the terminal app and the desktop app share my threads?

Yes. They use the same threads, settings, providers and keys. If the desktop app is open, the terminal app connects to it, so you can watch the same thread in both.
