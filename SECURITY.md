# Security

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately instead:

**[Report a vulnerability](https://github.com/Lucifer-xD/agent-flow-harness/security/advisories/new)** (the repository's Security tab)

It helps to include:

- what the problem is and what someone could do with it
- the steps to reproduce it, and the version you tested
- which part it affects: the desktop app, the phone app, the website or the relay

Please give us a reasonable chance to fix it before you share it publicly, and don't test against other people's accounts or computers.

## What's covered

- The latest release of the desktop and phone apps. Older versions don't get fixes, so update first and check that the problem is still there.
- The code in this repository, including the website and relay behind agentflowharness.com.

Problems in a model provider's own service belong with that provider.
